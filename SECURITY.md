# Security policy

## Supported versions

Security fixes are released for the latest release only. Upgrade to the newest version to receive them.

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

Report privately through GitHub: go to the [Security tab](https://github.com/faridlamaul/shiptag/security), choose **Report a vulnerability**, and include:

- the affected version (`shiptag` release, image tag, or commit),
- the platform and CI environment,
- steps to reproduce, and the impact you expect.

You will get an acknowledgement within 7 days. Once the issue is confirmed, a fix is released and the advisory is published with credit to you, unless you prefer to stay anonymous.

## Scope

shiptag handles publish tokens for GitHub, GitLab, and Bitbucket. Reports about token exposure (in logs, errors, outputs, or release notes), unintended releases, or tag manipulation are especially welcome.
